## 各フィールドの詳細

### 0x00 — key

定義表のキー（個体キー。例 a030+5）。セーブの Unit map キーと全件一致（実測）

- 型：str
- 確度：静的確認
- 元の研究出典表記：S1101§4（未公開の出典を含む）


### 0x1C — tag

DAT の unit タグ（個体キーを最初の + で切ったもの。例 a030+5 → a030）。0x582D90 が設定し、0x585AD0 はこれと ctx+0x34 で項目を引く。定義表のキーは +0x00（旧説明「例 a030+0・定義表のキー」は誤り）

- 型：str
- 確度：静的確認
- 元の研究出典表記：F§21, C(§93: 0x585AD0 が参照), S1101§4（未公開の出典を含む）


### 0x38 — race

種族（race）

- 型：str
- 確度：静的確認
- 元の研究出典表記：F§21（未公開の出典を含む）


### 0x54 — class

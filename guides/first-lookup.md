# 最初の調べもの — 戦闘開始のページを読む

**ゲームも解析ツールも起動せず、ブラウザだけで試せます。** ここでの目標は、関数の使い方を覚えることではなく、「分かったこと」と「まだ言えないこと」を区別して読むことです。

## 1. 調べる疑問を決める

今回は「通常戦闘が始まるとき、どの処理が関係するのか？」を調べます。

サイトの検索欄にBattle_ConstructSceneや0048D6A0と入力します。[実際の関数ページ](../reference/symbols/0048D6A0.md)を開いても構いません。数字は16進数で書かれたアドレスです。

## 2. 冒頭の説明を日常の言葉にする

研究ページでは、通常戦闘のscene2構築処理として、Unit・Map・乱数・Task・VMの初期化に進むと説明されています。

最初は「**通常戦闘を始めるためのデータや実行状態を用意する処理に関係している**」と捉えれば十分です。UnitやVMが分からなくても読み進められます。詳しくは[用語集](glossary.md)へ。

## 3. 確度と訂正を見る

このページの記録上の確度は「静的確認」です。プログラムを読んで得た結果であり、それだけで戦闘差し替えの実機成功を示すものではありません。

また、通常の復帰命令RETは0x48EA5Aにあり、以前の0x48EA38を終端とした解釈は誤りと記録されています。

**資料から言えること：** 通常戦闘の構築に関係する関数と、その終端についての訂正が記録されている。

**このページだけでは言えないこと：** この関数を置き換えればどんな戦闘システムでも正常に動く。引数や副作用がすべて判明している。変更用DLLが完成している。

数字を丸暗記する必要はありません。「訂正があるので、古い値だけを使わない」と分かれば十分です。

## 4. 関係する処理を一つたどる

「呼び出し元」は、その関数を呼ぶ側です。ページにはScene_DispatchGameModeが記載されています。

「呼び出し先」は、この関数から呼び出す側です。たとえば[Script_RunPass](../reference/symbols/004338D0.md)へ進むと、スクリプト処理との関係を調べる手掛かりになります。

掲載されているのは静的な直接CALL索引です。「ゲーム中に必ずこの順番で動く」「一覧にない呼び出しは存在しない」という意味ではありません。

## 5. 分かったことを一文にしてみる

> 通常戦闘の準備に関係する関数が研究されていて、関数の終端にも訂正があります。戦闘を別の仕組みにするには入口だけでなく出口やイベントの調査も必要そうです。

これは文章の例で、必須の投稿様式ではありません。「初期化とは何か分からなかった」という質問だけでも構いません。

## Pythonで検索する方法（任意）

Pythonと研究リポジトリのコピーがある場合に限り、次のコマンドも利用できます。ゲームのメモリを変更するものではありません。

```powershell
python -B tools/search.py symbols Battle_ConstructScene
python -B tools/search.py callers 0x0048D6A0
python -B tools/search.py callees 0x0048D6A0
```

ブラウザだけで読めるため、Pythonのインストールは必須ではありません。
